## R0 public-source investigation release

FyndEt R0 is a **limited, evidence-oriented investigation aid**, not a comprehensive digital footprint search. It supplies browser-only manual search links and a secure review-and-verification workflow for user-submitted public URLs. No search engine is queried automatically. Broad-web coverage is not claimed. Sources not cleared for commercial automated processing remain disabled. See [discovery coverage](docs/DISCOVERY_COVERAGE.md) for current limitations. No paid APIs, metasearch, GitHub or email-domain DNS investigation are included.
